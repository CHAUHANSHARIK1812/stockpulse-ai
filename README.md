# StockPulse AI

StockPulse AI is a Python-based stock market monitoring and analysis project. It brings stock data, financial news, and AI-assisted analysis together in one dashboard.

The main goal of the project is to make it easier to monitor stocks and understand the information behind market movements through a simple interface.

## Features

* Real-time stock monitoring
* Stock and market data analysis
* Financial news collection and analysis
* AI-assisted market insights
* Web-based dashboard
* Configurable application settings
* Separate modules for stock management, monitoring, and analysis

## Tech Stack

* **Python** — Core application and data processing
* **HTML/CSS** — Dashboard interface
* **AI APIs/Providers** — AI-assisted analysis
* **Financial APIs/Data Sources** — Stock and market information
* **Git & GitHub** — Version control

### Main Files

**`dashboard.py`**
Handles the main dashboard and application flow.

**`ai_analytics.py`**
Contains the analysis functionality used to generate insights from the available data.

**`ai_providers.py`**
Manages the AI provider integration.

**`stock_manager.py`**
Handles stock-related operations and data management.

**`stock_monitor.py`**
Provides stock monitoring functionality.

**`stock_monitor_enhanced.py`**
Contains an extended version of the stock monitoring functionality.

**`settings_manager.py`**
Manages application settings and configuration.

**`templates/dashboard.html`**
Contains the main dashboard interface.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/CHAUHANSHARIK1812/stockpulse-ai.git
```

### 2. Open the project

```bash
cd stockpulse-ai
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

> `requirements.txt` should contain the Python packages required by the project.

### 5. Configure API keys

If the application uses external APIs, add the required credentials through environment variables or the project's configuration system.

**Do not add API keys, passwords, or other private credentials directly to the repository.**

### 6. Run the application

```bash
python dashboard.py
```

The exact startup command may vary depending on the project configuration.

## How It Works

The application follows a simple flow:

```text
Stock & Market Data
        │
        ▼
Stock Monitoring
        │
        ├──────► Financial News
        │
        ▼
   Data Analysis
        │
        ▼
   AI-Assisted Analysis
        │
        ▼
     Dashboard
```

The monitoring modules collect and manage stock information, while the analysis modules process the available market and news data. The dashboard brings the results together in one place.
